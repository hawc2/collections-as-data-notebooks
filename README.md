# Collections-as-Data Notebooks

A curated list of Jupyter notebooks for querying and analyzing library collections as data.

## Versions

- **[V2.0](V2.0/README.md)** -- Updated March 2026. Current links, status assessments, and new resources including the GLAM Workbench, Library of Congress Jupyter Book, and modern OCR correction tools.

- **[V1.0](V1.0/README.md)** -- Original list compiled 2020-2021. Archived for reference. Includes a BERT-based OCR correction notebook (`BERT_OCR.ipynb`) that uses deprecated libraries.

## About

[Collections as data](https://collectionsasdata.github.io/) is a movement to mediate library collections in computational formats. Jupyter notebooks provide an accessible way to introduce data-based explorations of library collections. This repo curates notebooks from galleries, libraries, archives, and museums ([GLAM](https://glamlabs.io/)) worldwide.
