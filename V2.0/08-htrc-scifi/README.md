# HTRC Science Fiction Corpus Analysis

**Source:** [htrc/ef-api](https://data.htrc.illinois.edu/ef-api/) + [Thompson & Mimno's speculative fiction workset](https://github.com/laurejt/authorless-tms)
**Status:** Active -- EF API confirmed live March 2026

## What these notebooks do

**01_Build_SciFi_Corpus.ipynb** -- Builds a corpus of science fiction volumes from HathiTrust Extracted Features:
- Loads 1,206 speculative fiction volume IDs (Thompson & Mimno dataset, matched from Worlds Without End)
- Fetches metadata for all volumes via the EF API (title, author, date, publisher, access rights, LC classification)
- Downloads page-level Extracted Features for a sample of 20 volumes
- Saves metadata CSV and feature JSON files for analysis

**02_Analyze_SciFi_Corpus.ipynb** -- Analyzes the downloaded features:
- Vocabulary analysis: most common content words across the corpus
- Sentiment arcs: emotional trajectories across individual novels (AFINN lexicon, rolling mean smoothing)
- Vocabulary richness: type-token ratio across volumes and over time
- POS distribution: comparing noun/verb/adjective proportions across volumes
- Distinctive words: TF-IDF identification of words unique to each volume
- Decade-level sentiment: how the emotional tone of sci-fi shifts over the 20th century

## Data included

- `data/scifi-metadata.tsv` -- 1,206 HathiTrust volume IDs with author and title (from Thompson & Mimno)
- `data/scifi_metadata.json` -- cached EF API metadata (generated by notebook 01)
- `data/scifi_corpus_metadata.csv` -- parsed metadata DataFrame (generated by notebook 01)
- `data/ef_samples/*.json` -- page-level features for sample volumes (generated by notebook 01)

**HTRC is being suspended at end of December 2026.** The EF API is live as of March 2026.

- EF API: `https://data.htrc.illinois.edu/ef-api/volumes/{htid}` -- live, returns EF Schema 3.0 JSON
- Volume IDs with special characters need encoding: `:` -> `+`, `/` -> `=`
- No authentication required
- Bulk data via rsync: `data.analytics.hathitrust.org::features-2025.04/`
- [TORCHLITE](https://htrc.github.io/torchlite/) provides a web-based interface

## About the Thompson & Mimno dataset

Laure Thompson and David Mimno built this as part of an HTRC Advanced Collaborative Support project. They matched title-author pairs from [Worlds Without End](https://worldswithoutend.com/) (18,809 works by 3,620 authors, 1900-2010) against the HathiTrust catalog, producing 1,206 matched volumes. A larger version (2,454 volumes) titled "20th Century English-Language Speculative Fiction" is available as an [HTRC Recommended Workset](https://analytics.hathitrust.org/staticrecommendedworksets).

## Expanding the corpus

- Add more volume IDs to `data/scifi-metadata.tsv` and re-run notebook 01
- The HTRC Solr endpoint (`solr2.htrc.illinois.edu`) supports subject searching via the `hathiTools` R package
- Cross-reference ISFDB (isfdb.org) or WorldCat for additional sci-fi ISBNs/OCLCs, then resolve to HathiTrust IDs via the Bib API
- Ted Underwood's [fiction metadata](http://data.analytics.hathitrust.org/genre/fiction_metadata.csv) covers 101K fiction volumes (useful as a comparison corpus)
