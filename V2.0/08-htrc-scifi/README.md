# HTRC Science Fiction Corpus Analysis

**Source:** [htrc/ef-api](https://data.htrc.illinois.edu/ef-api/) + [Thompson & Mimno's speculative fiction worksets](https://github.com/laurejt/sf-in-hathitrust)
**Status:** Active -- EF API confirmed live March 2026

## Worksets

Two Thompson & Mimno worksets are available in `data/`:

| File | Volumes | Works | Authors | Scope |
|------|---------|-------|---------|-------|
| `sf-hathitrust-volumes.tsv` | 5,811 | 2,235 | 1,201 | 20th-c. English-language speculative fiction (1900-2010) |
| `sf-hathitrust-anthologies.tsv` | 918 | 669 | 288 | Anthology subset of above |
| `scifi-metadata.tsv` | 1,206 | -- | -- | Original 2018 workset (from `authorless-tms`) |

The 5,811-volume set supersedes the original 1,206-volume set. It was built by matching [Worlds Without End](https://worldswithoutend.com/) (18,809 works) against HathiTrust, then expanding with computational text similarity. Fields include HathiTrust ID, catalog record, WWEnd ID, ISFDB ID, title, author, year. Listed as an [HTRC Recommended Workset](https://analytics.hathitrust.org/staticrecommendedworksets).

## What these notebooks do

**01_Build_SciFi_Corpus.ipynb** -- Builds a corpus of science fiction volumes from HathiTrust Extracted Features:
- Loads speculative fiction volume IDs from the Thompson & Mimno worksets
- Fetches metadata for all volumes via the EF API (title, author, date, publisher, access rights, LC classification)
- Downloads page-level Extracted Features for a sample of 22 volumes
- Saves metadata CSV and feature JSON files for analysis

**02_Analyze_SciFi_Corpus.ipynb** -- Analyzes the downloaded features:
- Vocabulary analysis: most common content words across the corpus
- Sentiment arcs: emotional trajectories across individual novels (AFINN lexicon, rolling mean smoothing)
- Vocabulary richness: type-token ratio across volumes and over time
- POS distribution: comparing noun/verb/adjective proportions across volumes
- Distinctive words: TF-IDF identification of words unique to each volume
- Decade-level sentiment: how the emotional tone of sci-fi shifts over the 20th century

## About the Thompson & Mimno worksets

Laure Thompson (now at Princeton CDH) and David Mimno built the original 1,206-volume workset for their COLING 2018 paper "Authorless Topic Models" ([laurejt/authorless-tms](https://github.com/laurejt/authorless-tms)). They later expanded it to 5,811 volumes through an HTRC Advanced Collaborative Support project ([laurejt/sf-in-hathitrust](https://github.com/laurejt/sf-in-hathitrust), last updated Jan 2026). The expanded set adds WWEnd and ISFDB cross-references and was presented at ACH 2021 and DH2020.

## Expanding the corpus

- Add more volume IDs to `data/scifi-metadata.tsv` and re-run notebook 01
- The HTRC Solr endpoint (`solr2.htrc.illinois.edu`) supports subject searching via the `hathiTools` R package
- Cross-reference ISFDB (isfdb.org) or WorldCat for additional sci-fi ISBNs/OCLCs, then resolve to HathiTrust IDs via the Bib API
- Ted Underwood's [fiction metadata](http://data.analytics.hathitrust.org/genre/fiction_metadata.csv) covers 101K fiction volumes (useful as a comparison corpus)
